# How do I delete a project in dbt?

To delete a project in dbt, you must be the account owner or have admin privileges.

1. From dbt, click on your account name in the left side menu and select **Account settings**.

![Open Account settings from the account menu in the left sidebar](/img/docs/dbt-platform/account-settings-menu.png?v=2 "Open Account settings from the account menu in the left sidebar")Open Account settings from the account menu in the left sidebar

2. In **Account Settings**, select **Projects**. Click the project you want to delete from the **Projects** page.
3. Click **Edit** in the upper right corner of **Project details**. A **Delete** option appears.
4. Click **Delete**. Confirm the action to immediately delete the project without additional password prompts. The project is deleted immediately after confirmation. Once a project is deleted, this action cannot be undone.

![Delete projects](/img/docs/dbt-platform/delete_projects_from_dbt_cloud.png?v=2 "Delete projects")Delete projects
